# Design previews

Static mock-ups of the new American Warrior Armor look. They are not part of the Shopify theme.

Run from the repo root so the logo and hero video load:

    python3 -m http.server 8765

Then open:
- http://127.0.0.1:8765/previews/home-preview.html
- http://127.0.0.1:8765/previews/collection-preview.html

The real styling lives in `assets/theme.scss.liquid`; these files only mimic it.
